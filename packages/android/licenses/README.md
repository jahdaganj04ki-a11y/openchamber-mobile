# Licenses

Every binary and library the APK ships gets its license file here, named after
the binary, with the version that was built and the source it came from.

The About surface of the app lists the same entries, so a user can read them
on the phone.

The binaries the app is planned to ship:

| Binary | License | Source |
| --- | --- | --- |
| Bun | MIT | https://github.com/oven-sh/bun |
| OpenCode | MIT | https://github.com/sst/opencode |
| git | GPL-2.0 | https://git-scm.com |
| ripgrep | MIT | https://github.com/BurntSushi/ripgrep |
| bash | GPL-3.0 | https://www.gnu.org/software/bash |

The Kotlin and Compose libraries come from Maven and carry their own
license files inside their artifacts. They are listed in the About surface by
name and license.
